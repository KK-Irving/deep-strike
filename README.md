# 深空突袭 · DEEP STRIKE

一款纯前端、零依赖的纵版街机 **肉鸽射击** 游戏(打飞机)。
画面由 Canvas 2D 实时绘制,音效与背景音乐由 WebAudio 实时合成——没有任何素材文件,也不需要服务器。

**当前版本:v2.0.0**

## 如何运行

直接**双击 `index.html`** 用现代浏览器(Chrome / Edge / Firefox)打开即可。
无需安装、无需联网、无需构建。本地调试可运行 `python tools/serve.py`(无缓存开发服务器)。

## 核心玩法:肉鸽构筑

- 击坠敌机掉落**经验晶体**,靠近自动吸取,积满升级
- 升级时战场暂停,弹出**三选一强化卡片**(点击或按 `1/2/3`),多级连升可连续选择
- **33 种强化卡片**(含隐藏卡「基因扩展」与 3 张诅咒风险卡),分普通 / 稀有 / 史诗三档稀有度,可叠加成层:
  火力强化 · 急速射击 · 推进器 · 引力场 · 经验芯片 · 连击锁链 · 并列弹道 ·
  侧翼弹 · 尾炮 · 贯穿弹 · 要害打击 · 歼灭装填 · 反击风暴 · 裂变弹 · 追踪导弹 · 护盾发生器 ·
  时滞力场(敌弹整体减速) · 幻影僚机(自动索敌僚机) · 空间裂隙(黑洞撕碎弹幕) ·
  **激光主炮**(质变:贯穿光束持续灼烧,并列弹道生成并列光束) ·
  **散射炮**(质变:近程宽扇爆发,弹丸射程衰减) ·
  **轨道炮**(质变:蓄力高速磁轨弹,单发高伤强贯穿,与暴击/贯穿联动) ·
  **电弧发生器**(质变:链式闪电自动在敌群间跳跃,与并列/裂变联动) ·
  **回旋刃**(质变:掷出双程回旋刃,去回双重切割,可并排多枚) ·
  生命上限 · 纳米修复 · 击杀汲取 · 复合装甲 · 不屈意志 ·
  **诅咒卡**(低权重出现,红色描边,逐级增益/逐级加重代价):玻璃大炮(伤害+20%/级,生命上限-8%/级) · 脆刃(暴击+6%/级,受伤×(1+10%×级)) · 贪婪契约(得分星晶+10%/级,敌弹加速+3%/级)
**统一 5 级制**:所有卡片上限 5 级,逐级成长;**5 级后再次抽到同卡即为「进化」**——传说进化卡必现于三选一,质变出全新战力(33 张卡 × 33 条进化路线一一对应),诅咒卡的进化会净化其代价:
  ⚡聚变弹头(溅射) · 🔥超频引擎(射速) · ❤️泰坦血统(巨血) · ➹量子穿甲 · ✖处决者(暴击强化) ·
  ➤天罚矩阵(导弹群) · ✷链式裂变(二次分裂) · ◇圣盾爆发(破盾清屏) · 🔦湮灭主炮(宽幅激光) ·
  🎇万弹齐发(无衰减散射) · ⏳时间冻结(每波开局弹幕静止) ·
  🌠磁暴风(轨道炮:蓄力更快+无限贯穿) · 🌩雷霆领主(电弧:多跳+麻痹减速) ·
  🌪龙卷之核(回旋刃:增伤增大+投掷折返更快)
- **多机体**:突击机(均衡) / 重装堡垒(HP140+甲10%,2800★) / 幽灵(HP75+极速+磁吸,1800★) /

## 关卡目标

- 每波需**击坠规定数量的敌机**才能过关(HUD 右上角实时显示进度),纯躲避无法通关——
  出怪队列耗尽而配额未达成时,敌方会持续派出增援
- BOSS 波目标:击毁旗舰
- **旗舰连战**(主菜单 `B`):无杂兵连续挑战不断增强的旗舰——第 k 阶段按波号 5k 构造,
  红/青/紫变体自然轮换,每阶段奖励升级+遗物三选一并回复 15% 生命;独立最佳纪录,
  芯片按阶段结算(8~24◈)每日限领一次

## 道具

- **P** 火力提升(最高 5 级:单发 → 双发 → 三向 → 四向 → 五向)
- **S** 护盾:抵挡一次伤害
- **B** 炸弹 +1(清空全屏弹幕并重创敌机,释放瞬间自带短暂无敌)
- **♥** 回复 40 生命(溢出转化为分数)
- **×2** 双倍得分 10 秒 · **F** 狂热:射速提升 10 秒(激光等持续武器以增伤等价受益)
- **❄** 寒霜:敌机与弹幕整体减速 5 秒(旗舰免疫) · **M** 磁力风暴:吸取全场晶体与道具

- 连续击坠累积 COMBO,连击数每 8 个提升一档倍率(最高 ×4),中断时间可通过卡片延长
- 每波达成目标奖励 `200 + 100 × 波数`

## 测试(e2e)

- 依赖 Playwright + 本机 Chrome(headless)。准备:`npm install`,并确保本机装有 Chrome 或 Edge;
  浏览器路径按 `CHROME_PATH` → 常见安装路径 → PATH → Playwright 自带 Chromium 依次解析。
- **一键全量**:`npm test`(等价 `node tools/_e2e_all.js`),全部套件顺序执行,任一失败即退出码 1。
  新增套件放入 `tools/` 即被自动发现,无需注册。
  - `npm test -- --only=combat,shop2` 只跑匹配套件;`--jobs=2` 并发;`--timeout=300` 单套件超时(秒);
    `--quiet` 只打结果;`--list` 只列套件
  - 运行日志写在 `tools/_logs/`(已 gitignore),失败时运行器自动打印日志尾部
- 单跑某套件:`node tools/_e2e_combat.js`;输出格式统一:逐条 `ok/FAIL` + 末行
  `PASS/FAIL 套件名 — n/m`,便于肉眼与脚本双重判定。

## 技术要点

- **固定逻辑分辨率 480×720**,按窗口等比缩放并适配 devicePixelRatio,任意屏幕不变形
- **滚动安全居中布局**:全部浮层(菜单/商城/升级/结算)超高时自动转为可滚动,任意窗口尺寸内容完整可达;标题与面板响应式缩放
- **deltaTime 驱动**的更新循环(单帧上限 33ms),切后台再切回不会"瞬移"
- 带静态机体的实体(玩家/敌机/BOSS/道具)**预渲染为离屏精灵**,运行时仅贴图,
  消除逐帧 shadowBlur 开销;压力场景实测单帧 < 0.5ms
- 碰撞检测采用**圆形包围盒**;子弹支持贯穿(命中缓存去重)/裂变/暴击/追踪
- 粒子(500)/飘字(60)/敌弹(240)均设容量上限;敌方弹速在第 18 波后封顶,经验曲线平滑
- 背景星云预渲染到离屏 Canvas,运行时仅贴图
- **挑战种子按波派生**:每日/周挑战以日期种子为每波派生独立随机子流,出怪序列与精英词缀
  与战斗过程完全解耦——任意玩家、任意尝试、任意设备严格一致;抽卡按序号派生同理。
  确定性契约由测试锁死:`_e2e_determinism` 同种子双开对比(波次构成/抽卡序列/同 dt 步进行为),
  `_e2e_static` 白名单静态扫描全部种子流消费点(表现层零消费)
- 音乐使用 16 步音序器 + lookahead 调度,节奏不受主循环波动影响
- 切出窗口 / 最小化时**自动暂停**,不会"背板"阵亡
- 零依赖、零构建,可直接以 file:// 协议运行
