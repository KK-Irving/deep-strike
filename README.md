# 深空突袭 · DEEP STRIKE

一款纯前端、零依赖的纵版街机 **肉鸽射击** 游戏(打飞机)。
画面由 Canvas 2D 实时绘制,音效与背景音乐由 WebAudio 实时合成——没有任何素材文件,也不需要服务器。

**当前版本:v0.4.3**

## 如何运行

直接**双击 `index.html`** 用现代浏览器(Chrome / Edge / Firefox)打开即可。
无需安装、无需联网、无需构建。本地调试可运行 `python tools/serve.py`(无缓存开发服务器)。

## 核心玩法:肉鸽构筑

- 击坠敌机掉落**经验晶体**,靠近自动吸取,积满升级
- 升级时战场暂停,弹出**三选一强化卡片**(点击或按 `1/2/3`),多级连升可连续选择
- **26 种强化卡片**(另有隐藏卡「基因扩展」),分普通 / 稀有 / 史诗三档稀有度,可叠加成层:
  火力强化 · 急速射击 · 推进器 · 引力场 · 经验芯片 · 连击锁链 · 并列弹道 ·
  侧翼弹 · 尾炮 · 贯穿弹 · 要害打击 · 歼灭装填 · 反击风暴 · 裂变弹 · 追踪导弹 · 护盾发生器 ·
  时滞力场(敌弹整体减速) · 幻影僚机(自动索敌僚机) · 空间裂隙(黑洞撕碎弹幕) ·
  **激光主炮**(质变:贯穿光束持续灼烧,并列弹道生成并列光束) ·
  **散射炮**(质变:近程宽扇爆发,弹丸射程衰减) ·
  生命上限 · 纳米修复 · 击杀汲取 · 复合装甲 · 不屈意志
- **质变武器互斥**:激光/散射两条武器路线二选一,选定后对手路线移出卡池,
  火力等级 P 道具对两条路线均有适配(激光加宽增伤/散射增加弹丸)
- **强化槽位**:最多同时持有 5 种不同强化(叠层不占槽);槽满后选新卡需**丢弃一项旧强化**,
  羁绊随之实时重组——构筑即取舍;隐藏卡「🧬 基因扩展」仅在槽满时出现,可突破上限
- **14 种羁绊**:同时持有特定卡片组合自动觉醒,弹出道具级横幅:

  | 羁绊 | 组合 | 效果 |
  | --- | --- | --- |
  | 弹幕风暴 | 裂变弹 + 贯穿弹 | 裂变小弹获得贯穿 |
  | 天罗地网 | 侧翼弹 + 尾炮 | 周期释放全向环形弹 |
  | 猎杀时刻 | 追踪导弹 + 要害打击 | 导弹必定暴击 |
  | 移动堡垒 | 护盾发生器 + 反击风暴 | 护盾充能时间减半 |
  | 超载核心 | 急速射击 + 火力强化 | 射击间隔额外 -15% |
  | 歼灭协议 | 要害打击 + 火力强化 | 暴击倍率提升至 4.5 倍 |
  | 维度撕裂 | 时滞力场 + 空间裂隙 | 裂隙范围 +60% |
  | 僚机协议 | 幻影僚机 + 追踪导弹 | 僚机改射追踪导弹 |
  | 时间领主 | 时滞力场 + 急速射击 | 时滞每层提升至 30% |
  | 聚能协议 | 激光主炮 + 火力强化 | 激光伤害 +60% |
  | 压制弹幕 | 散射炮 + 侧翼弹 | 散射与侧翼弹丸数 +2 |
  | 生机涌动 | 护盾发生器 + 纳米修复 | 护盾破碎时回复 15 生命 |
  | 荆棘装甲 | 复合装甲 + 反击风暴 | 受击时回复 5 生命 |
  | 血怒共振 | 击杀汲取 + 要害打击 | 暴击时额外回复 2 生命 |

  每次出击都是一条专属构筑路线。

## 关卡目标

- 每波需**击坠规定数量的敌机**才能过关(HUD 右上角实时显示进度),纯躲避无法通关——
  出怪队列耗尽而配额未达成时,敌方会持续派出增援
- BOSS 波目标:击毁旗舰

## 敌机图鉴

- **无人机**(红):直冲 + 小幅摆动,成群出现
- **摇摆机**(粉):蛇形前进,发射瞄准弹
- **重装舰**(橙):血厚,发射三向散射弹,击毁必掉道具
- **狙击机**(紫):进场悬停,发射高速狙击弹
- **精英机**(第 3 波起概率随队):血量 ×4 / 体型 ×1.3 / 分数 ×4 / 必掉道具,词缀:
  - **迅捷**:高速机动
  - **铁壁**:装甲额外强化,行动迟缓
  - **分裂**:死亡时裂解为 3 架无人机
  - **狂暴**:火力密度大增
  - **幽影**:周期相位,免疫伤害且停止开火
  - **复仇**:死亡时释放 12 向环形弹幕反扑
  - **自爆蜂**(橙):追踪俯冲,接近或引信耗尽自爆成 8 向环弹——提前击坠可拆除
  - **护盾兵**(青):下半球护盾周期开合,绕至上方/趁间隙/炸弹/导弹绕后可破
  - 第 10 波起 35% 概率出现**双词缀精英**(词缀叠加)
- **事件波**:
  - **☄ 陨石带**(第 3/8/13…波):陨石吸收双方弹幕构成临时掩体,击碎得经验
  - **▽ 补给空投**(第 4/9/14…波):3 只补给箱缓降,接住即得物资,走位取舍
- **旗舰 BOSS**(每 5 波):三阶段弹幕,血量随波数增长,击毁掉落大量经验
  - **敌方旗舰**(红,第 5/15/25…波):瞄准三连 → 环形弹幕 → 四向螺旋
  - **暴风旗舰**(青,第 10/20/30…波):血量 ×1.3 / 机动 +35%,窄角狙击 → 双臂螺旋 → 螺旋+瞄准齐射

## 道具

- **P** 火力提升(最高 5 级:单发 → 双发 → 三向 → 四向 → 五向)
- **S** 护盾:抵挡一次伤害
- **B** 炸弹 +1(清空全屏弹幕并重创敌机,释放瞬间自带短暂无敌)
- **♥** 生命 +1

主菜单内:`D` 每日挑战 · `H` 玩法说明 · `T` 战绩档案 · `Esc` 返回。
**生命系统**:战机拥有生命值(初始 100,随等级与卡片成长),弹幕 25 / 接触 35 伤害,
归零即坠毁——生存向构筑(装甲/修复/汲取/不屈)与输出构筑同样重要。
**每日挑战**:按日期播种的固定关卡——全天所有玩家/所有尝试的出怪序列、精英词缀与抽卡序列完全一致,独立当日纪录,比拼规划与构筑功底。
触屏设备:单指拖动移动(自动连发),双指点按放炸弹。

## 成就

12 项成就(首杀 / 单局 60 击坠 / 抵达 5·10·15 波 / 旗舰猎手·克星 / 3 条羁绊 / 单局 10 级 / 30 连击 / 累计 10 精英 / 火力全开),
解锁瞬间全屏播报,战绩档案页可查看进度(🏆/🔒)。

暂停页与结算页展示**本局构筑摘要**(强化芯片+羁绊徽章)与战报(击坠/精英/等级/最高连击),
濒死时屏幕边缘红色脉动警示。

## 计分规则

- 连续击坠累积 COMBO,连击数每 8 个提升一档倍率(最高 ×4),中断时间可通过卡片延长
- 每波达成目标奖励 `200 + 100 × 波数`
- 精英机额外奖励分;最高分与累计战绩(出击次数/击坠数/最远波次等)保存在浏览器本地(localStorage)

## 技术要点

- **固定逻辑分辨率 480×720**,按窗口等比缩放并适配 devicePixelRatio,任意屏幕不变形
- **deltaTime 驱动**的更新循环(单帧上限 33ms),切后台再切回不会"瞬移"
- 带静态机体的实体(玩家/敌机/BOSS/道具)**预渲染为离屏精灵**,运行时仅贴图,
  消除逐帧 shadowBlur 开销;压力场景实测单帧 < 0.5ms
- 碰撞检测采用**圆形包围盒**;子弹支持贯穿(命中缓存去重)/裂变/暴击/追踪
- 粒子(500)/飘字(60)/敌弹(240)均设容量上限;敌方弹速在第 18 波后封顶,经验曲线平滑
- 背景星云预渲染到离屏 Canvas,运行时仅贴图
- 音乐使用 16 步音序器 + lookahead 调度,节奏不受主循环波动影响
- 切出窗口 / 最小化时**自动暂停**,不会"背板"阵亡
- 零依赖、零构建,可直接以 file:// 协议运行
