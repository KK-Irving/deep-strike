# 深空突袭 · DEEP STRIKE

一款纯前端、零依赖的纵版街机 **肉鸽射击** 游戏(打飞机)。
画面由 Canvas 2D 实时绘制,音效与背景音乐由 WebAudio 实时合成——没有任何素材文件,也不需要服务器。

**当前版本:v0.1.2**

## 如何运行

直接**双击 `index.html`** 用现代浏览器(Chrome / Edge / Firefox)打开即可。
无需安装、无需联网、无需构建。本地调试可运行 `python tools/serve.py`(无缓存开发服务器)。

## 核心玩法:肉鸽构筑

- 击坠敌机掉落**经验晶体**,靠近自动吸取,积满升级
- 升级时战场暂停,弹出**三选一强化卡片**(点击或按 `1/2/3`),多级连升可连续选择
- **16 种强化卡片**,分普通 / 稀有 / 史诗三档稀有度,可叠加成层:
  火力强化 · 急速射击 · 推进器 · 引力场 · 经验芯片 · 连击锁链 · 并列弹道 ·
  侧翼弹 · 尾炮 · 贯穿弹 · 要害打击 · 歼灭装填 · 反击风暴 · 裂变弹 · 追踪导弹 · 护盾发生器
- **6 种羁绊**:同时持有特定卡片组合自动觉醒,弹出道具级横幅:

  | 羁绊 | 组合 | 效果 |
  | --- | --- | --- |
  | 弹幕风暴 | 裂变弹 + 贯穿弹 | 裂变小弹获得贯穿 |
  | 天罗地网 | 侧翼弹 + 尾炮 | 周期释放全向环形弹 |
  | 猎杀时刻 | 追踪导弹 + 要害打击 | 导弹必定暴击 |
  | 移动堡垒 | 护盾发生器 + 反击风暴 | 护盾充能时间减半 |
  | 超载核心 | 急速射击 + 火力强化 | 射击间隔额外 -15% |
  | 歼灭协议 | 要害打击 + 火力强化 | 暴击倍率提升至 4.5 倍 |

  每次出击都是一条专属构筑路线。

## 关卡目标

- 每波需**击坠规定数量的敌机**才能过关(HUD 右上角实时显示进度),纯躲避无法通关——
  出怪队列耗尽而配额未达成时,敌方会持续派出增援
- BOSS 波目标:击毁旗舰

## 敌机图鉴

- **无人机**(红):直冲 + 小幅摆动,成群出现
- **摇摆机**(粉):蛇形前进,发射瞄准弹
- **重装舰**(橙):血厚,发射三向散射弹,击毁必掉道具
- **狙击机**(紫):进场悬停,发射高速狙击弹
- **精英机**(第 3 波起概率随队):血量 ×4 / 体型 ×1.3 / 分数 ×4 / 必掉道具,词缀:
  - **迅捷**:高速机动
  - **铁壁**:装甲额外强化,行动迟缓
  - **分裂**:死亡时裂解为 3 架无人机
  - **狂暴**:火力密度大增
- **旗舰 BOSS**(每 5 波):三阶段弹幕——瞄准三连 → 环形弹幕 → 四向螺旋,血量随波数增长,击毁掉落大量经验

## 道具

- **P** 火力提升(最高 5 级:单发 → 双发 → 三向 → 四向 → 五向)
- **S** 护盾:抵挡一次伤害
- **B** 炸弹 +1(清空全屏弹幕并重创敌机,释放瞬间自带短暂无敌)
- **♥** 生命 +1

## 计分规则

- 连续击坠累积 COMBO,连击数每 8 个提升一档倍率(最高 ×4),中断时间可通过卡片延长
- 每波达成目标奖励 `200 + 100 × 波数`
- 精英机额外奖励分;最高分与累计战绩(出击次数/击坠数/最远波次等)保存在浏览器本地(localStorage)

## 技术要点

- **固定逻辑分辨率 480×720**,按窗口等比缩放并适配 devicePixelRatio,任意屏幕不变形
- **deltaTime 驱动**的更新循环(单帧上限 33ms),切后台再切回不会"瞬移"
- 带静态机体的实体(玩家/敌机/BOSS/道具)**预渲染为离屏精灵**,运行时仅贴图,
  消除逐帧 shadowBlur 开销;压力场景实测单帧 < 0.5ms
- 碰撞检测采用**圆形包围盒**;子弹支持贯穿(命中缓存去重)/裂变/暴击/追踪
- 粒子(500)/飘字(60)/敌弹(240)均设容量上限
- 背景星云预渲染到离屏 Canvas,运行时仅贴图
- 音乐使用 16 步音序器 + lookahead 调度,节奏不受主循环波动影响
- 切出窗口 / 最小化时**自动暂停**,不会"背板"阵亡
- 零依赖、零构建,可直接以 file:// 协议运行
