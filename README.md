# 深空突袭 · DEEP STRIKE

一款纯前端、零依赖的纵版街机射击游戏(打飞机)。
画面由 Canvas 2D 实时绘制,音效与背景音乐由 WebAudio 实时合成——没有任何素材文件,也不需要服务器。

## 如何运行

直接**双击 `index.html`** 用现代浏览器(Chrome / Edge / Firefox)打开即可。
无需安装、无需联网、无需构建。

## 玩法

你驾驶一艘突击机深入敌方星域,敌机一波接一波来袭,每隔 5 波遭遇旗舰 BOSS。
击落敌机获取分数与道具,活得更久、打得更狠,冲击最高分。

### 操作

| 按键 | 功能 |
| --- | --- |
| W A S D / 方向键 | 移动 |
| J / 空格 | 手动射击(按住连发) |
| F | 自动连发开关(默认开启) |
| K | 清屏炸弹 |
| Shift | 低速精准移动(显示判定点) |
| P / Esc | 暂停 |
| M | 静音 |
| Enter | 开始 / 重新开始 |

触屏设备:单指拖动移动(自动连发),双指点按放炸弹。

### 敌机图鉴

- **无人机**(红):直冲 + 小幅摆动,成群出现
- **摇摆机**(粉):蛇形前进,发射瞄准弹
- **重装舰**(橙):血厚,发射三向散射弹,击毁必掉道具
- **狙击机**(紫):进场悬停,发射高速狙击弹
- **旗舰 BOSS**(每 5 波):三阶段弹幕——瞄准三连 → 环形弹幕 → 四向螺旋,血量随波数增长

### 道具

- **P** 火力提升(最高 5 级:单发 → 双发 → 三向 → 四向 → 五向)
- **S** 护盾:抵挡一次伤害
- **B** 炸弹 +1(清空全屏弹幕并重创敌机,释放瞬间自带短暂无敌)
- **♥** 生命 +1

### 计分规则

- 连续击坠累积 COMBO,连击数每 8 个提升一档倍率(最高 ×4),2 秒未击坠则中断
- 每波清版奖励 `200 + 100 × 波数`
- 最高分自动保存在浏览器本地(localStorage)

## 技术要点

- **固定逻辑分辨率 480×720**,按窗口等比缩放并适配 devicePixelRatio,任意屏幕不变形
- **deltaTime 驱动**的更新循环(单帧上限 33ms),切后台再切回不会"瞬移"
- 碰撞检测采用**圆形包围盒**,实现简单且精确
- 子弹 / 爆炸使用 `globalCompositeOperation: 'lighter'` 叠加发光,避免昂贵的 shadowBlur 滥用
- 背景星云预渲染到离屏 Canvas,运行时仅贴图
- 音乐使用 16 步音序器 + lookahead 调度,节奏不受主循环波动影响
- 切出窗口 / 最小化时**自动暂停**,不会"背板"阵亡
- 零依赖、零构建,可直接以 file:// 协议运行
